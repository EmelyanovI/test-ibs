# test-ibs

Прототип таблицы сотрудников на React + TypeScript. Виртуальный скролл через TanStack Table и TanStack Virtual — 10 000 моковых строк, сортировка по клику на заголовок.

## Запуск

```bash
cd test-ibs
```

Первый запуск (поставит зависимости, если нет `node_modules`):

```bash
npm start
```

Повторный:

```bash
npm run dev
```

Откроется http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```
